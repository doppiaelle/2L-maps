# Store metadata

Fastlane reads this directory. Titles, descriptions, keywords and release notes live here in
plain files so that a wording change is a reviewable diff — the App Store description is where a
product promises things the app does not do, and that is a rejection as surely as a missing
disclosure is.

Screenshots are **not** committed: they are large, they go stale on every design change, and
regenerating them is a device task rather than a repository one. The capture flow belongs with
the Maestro flows once hardware exists.
